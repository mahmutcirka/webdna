# Public release checklist

WebDNA is prepared for publication but **nothing is pushed or published automatically**. A maintainer must run these steps.

## Automated checks

```bash
npm ci
npx playwright install chromium
npm run format:check
npm run lint
npm run typecheck
npm run test:all
npm run eval
npm run build
npm run check:release
```

`check:release` fails on likely secrets, committed `.env` files, `data/` scan output, databases, build output, unexpected binaries, invented star/download badges and "% AI-generated" wording.

## Manual checklist

- [ ] `git status` shows no `data/`, `.env`, `.next/`, `dist/`, logs or screenshots of third-party sites.
- [ ] `apps/web/src/sample/sample-report.json` and `apps/web/public/sample/*` were generated by `npm run sample-report` from the synthetic fixture and are labelled "Example data".
- [ ] `docs/screenshots/*` show only the landing page and the sample report.
- [ ] README makes no accuracy, benchmark, user-count, star or CI-badge claims.
- [ ] Signature provenance in `packages/detectors/signatures/*.json` is accurate; unreproduced markers are `experimental`.
- [ ] `THIRD_PARTY_NOTICES.md` matches the installed direct dependencies.
- [ ] Create the repository `mahmutcirka/webdna` (the README clone URL assumes this name; adjust if you publish elsewhere).
- [ ] Enable GitHub private vulnerability reporting (SECURITY.md points to it; no e-mail is published).
- [ ] A clean clone can follow README → `npm install` → `npx playwright install chromium` → `npm run dev` → scan a public URL.
- [ ] Enable GitHub secret scanning, push protection and Dependabot alerts in the repository settings.

## Commands to publish (run them yourself)

```bash
git add -A
git commit -m "Initial public release of WebDNA 0.1.0"
gh repo create mahmutcirka/webdna --public --source . --remote origin --description "Website intelligence and evidence-based AI-origin analysis"
git push -u origin main
git tag v0.1.0
git push origin v0.1.0
```

Optionally pin GitHub Actions to commit SHAs after the first Dependabot run (see `.github/dependabot.yml`).
